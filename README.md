## Estructura del Proyecto

- `/frontend`: Lógica de la interfaz de usuario y rutas.
- `/backend`: API y controladores del sistema.
- `/assets`: Recursos estáticos (CSS, imágenes).
- `/database`: Scripts de base de datos.
